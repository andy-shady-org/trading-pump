# Run rc.11-tp20

**Exploratory, not counted.** rc.11's config with the take-profit lowered
from +50% to +20% on both lanes, run beside rc.11 on the same graduates, to
measure live what a lower target does. It has no verdict and no lane climbs
a stage on it.

## Why it is not counted

- **It was chosen after looking at the data.** The +20% target came out of
  the study of rc.11's own first night
  ([`RESULTS.md` §6.19](../RESULTS.md#619-rc9-and-rc10-stopped-early-why-the-instant-lane-crashed-2026-10-31)),
  where the instant lane's +50% did worst. A rule picked on the hours it is
  then judged on is in-sample, whatever it shows.
- **Nothing was registered before the start.** No question, config hash or
  verdict file was committed to this repository before 06:00:15 UTC on
  2026-10-31, so there is nothing fixed to judge it against.
- **It is not independent of rc.11.** Both runs see the same graduates at
  the same times; the difference between them is the exit, and only that.

What it is good for: on the same coins and hours as rc.11, how many
positions +20% closes as wins that +50% rides into the stop. That feeds the
choice of target for the next counted run, `pump-12`, which the study says
is to decide between a lower fixed target and an adaptive one.

## Set-up (recorded 2026-10-31, after the start)

- **Code:** the rc.11 build, trading-pump `v0.4.0rc4` on trading-core
  `v0.2.2` (`v0.4.0rc5` was tagged after this run started).
- **Config:** `runtime-pump/configs/rc11-tp20.json`: rc.11's
  `configs/rc11-paper.json` with `take_profit_pct` `0.2` in `lane.exits`
  and `instant.exits`, and its own data folder. Its sha256 is not recorded
  in this repository.
- **Started:** 2026-10-31 06:00:15 UTC. Planned end: not recorded in this
  repository.
- **Stage:** none; paper only.
