# Release records

A release's record lives in its `CHANGELOG.md` entry
(`### Release record – vX.Y.Z (YYYY-MM-DD)`). When it is too long for the
changelog, it goes here as `vX.Y.Z.md`, linked from the entry; the template
is [`RELEASE-GATE.md` §5](../RELEASE-GATE.md#5-release-record).

No release so far has needed a file here: every trading-pump record, from
`v0.4.0rc1` to `v0.4.0rc5`, is in [`CHANGELOG.md`](../../../CHANGELOG.md).

The two files this folder used to hold were not release records but the
running logs of pumpbot's paper pilots on v0.2.0 and v0.2.1. They moved,
unedited, to [`runs/`](../runs/README.md) on 2026-10-31:
[`v0.2.0-stage0.md`](../runs/v0.2.0-stage0.md) and
[`v0.2.1-stage0.md`](../runs/v0.2.1-stage0.md).
